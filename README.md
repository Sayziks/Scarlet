**SCARLET** – автономный, чистый и быстрый клиент для Windows для мгновенного подключения WireGuard-профилей. Программа создана для восстановления стабильного доступа к заблокированным ресурсам (Discord, YouTube, Telegram) и оптимизирована для онлайн-игр с минимальным пингом.

**Рабочие конфигурации уже встроены по умолчанию:** вам не нужно ничего настраивать, искать или скачивать отдельно — сразу после установки можно нажать «Подключить». При этом вы всегда можете добавить свои личные профили.

> **Примечание:** Данный репозиторий является официальной страницей дистрибуции программы. SCARLET распространяется в виде готовых сборок для систем **X64** и **ARM64**.

## Предустановленные профили

В программу уже интегрированы протестированные конфигурации под конкретные сценарии:

* **Games (Low Ping)** – маршрут через европейские узлы связи с минимальной задержкой и ровным графиком для Fortnite, CS2, Valorant и других сетевых игр.
* **YouTube & Twitch (4K)** – конфигурация с увеличенным размером пакета (MTU 1420) для непрерывного потокового видео высокого разрешения без буферизации.
* **Discord Voice** – профиль с маскировкой под голосовые протоколы для стабильной работы голосовых каналов, звонков и демонстрации экрана.
* **Telegram Fix** – режим обхода фильтрации для мгновенного подключения мессенджера на любых провайдерах и мобильном интернете.
* **Web Reserve** – универсальный резервный канал на альтернативном системном порту для повседневного серфинга.

## Почему SCARLET лучше Zapret и GoodbyeDPI?

| Параметр | Zapret / GoodbyeDPI | SCARLET |
| :--- | :--- | :--- |
| **Установка** | Сложная: ручной запуск консоли, батников (.bat) и подбор флагов | **В 1 клик:** запустил установщик и сразу пользуешься |
| **Встроенные профили** | Нет, нужно настраивать самостоятельно | **Да:** готовые конфиги под разные задачи уже вшиты |
| **Реакция антивирусов** | Детектится как RiskTool / HackTool из-за драйвера перехвата | **Антивирусы не ругаются:** чистый и доверенный софт |
| **Внедрение в память** | Да. Использует хуки и драйвер WinDivert, перехватывающий пакеты в памяти | **Нет.** Работает изолированно через стандартный сетевой драйвер Wintun |
| **Античиты игр** | Конфликтует с Vanguard, Easy Anti-Cheat и BattlEye (риск бана) | **Безопасно:** не затрагивает игровые процессы и память |
| **Стабильность Windows** | Ошибки драйвера перехвата нередко вызывают синие экраны (BSOD) | Стабильная фоновая служба без вылетов и утечек памяти |
| **Discord и голосовые чаты** | Требует отдельных сложных настроек для работы голоса | Звонки, стримы и голосовые комнаты работают из коробки |

## Как это устроено

* **Официальный стек WireGuard** – сетевой обмен идет через драйвер виртуального адаптера Wintun (разработка WireGuard LLC). Трафик изолирован и передается на максимальной скорости вашего канала.
* **Автономная служба ScarletManager** – соединение держит системная служба Windows, поэтому VPN не разрывается при закрытии окна.
* **Живой мониторинг сети** – встроенный график отслеживает задержку (ping) в реальном времени с наглядной цветовой индикацией качества связи.
* **Кнопка «Лучший профиль»** – программа автоматически тестирует все доступные серверы и оставляет подключенным самый быстрый.
* **Полная конфиденциальность** – программа не содержит аналитических модулей, не ведет логов и хранит все данные локально в `%APPDATA%\Scarlet`.

## Использование

### 1. Скачивание
Перейдите в раздел **[Releases](https://github.com/Sayziks/Scarlet/releases/latest)** и скачайте версию под ваш процессор:
* **`Scarlet X64.exe`** – для стандартных ПК и ноутбуков (Intel / AMD).
* **`Scarlet ARM64.exe`** – для устройств на базе Windows on ARM.

### 2. Установка
Запустите скачанный файл, подтвердите права администратора и нажмите **«Установить»**. Программа настроит службу и создаст ярлык за несколько секунд.

### 3. Подключение
В программе уже доступны встроенные профили. Просто выберите нужный и нажмите **«Подключить»** (или воспользуйтесь функцией **«Лучший профиль»** для автоматического выбора минимального пинга).

Для добавления личных конфигураций нажмите кнопку **«Добавить»** и скопируйте файлы `.conf` в открывшуюся папку.

### 4. Управление через трей
При нажатии на крестик окна SCARLET сворачивается в системный трей возле часов и продолжает держать соединение. Чтобы полностью закрыть программу, нажмите правой кнопкой мыши по значку в трее -> **«Выход»**.
