**SCARLET** – автономный, чистый и быстрый клиент для Windows для мгновенного подключения WireGuard-профилей. Программа создана для восстановления стабильного доступа к заблокированным ресурсам (Discord, YouTube, Telegram) и оптимизирована для онлайн-игр с минимальным пингом.

**Рабочие конфигурации уже встроены по умолчанию:** вам не нужно ничего настраивать, искать или скачивать отдельно — сразу после установки можно нажать «Подключить». При этом вы всегда можете добавить свои личные профили.

> **Примечание:** Данный репозиторий является официальной страницей дистрибуции программы. SCARLET распространяется в виде готовых сборок для систем **X64** и **ARM64**.

## Почему SCARLET лучше Zapret и GoodbyeDPI?

| Параметр | Zapret / GoodbyeDPI | SCARLET |
| :--- | :--- | :--- |
| **Установка** | Сложная: ручной запуск консоли, батников (.bat) и подбор флагов | **В 1 клик:** запустил установщик и сразу пользуешься |
| **Встроенные профили** | Нет, нужно настраивать самостоятельно | **Да:** рабочие конфиги уже вшиты по умолчанию |
| **Реакция антивирусов** | Детектится как RiskTool / HackTool из-за драйвера перехвата | **Антивирусы не ругаются:** чистый и доверенный софт |
| **Внедрение в память** | Да. Использует хуки и драйвер WinDivert, перехватывающий пакеты в памяти | **Нет.** Работает изолированно через стандартный драйвер Wintun |
| **Античиты игр** | Конфликтует с Vanguard (Valorant), Easy Anti-Cheat, вызывая бан или вылет | **Безопасно:** не триггерит защиту в играх |
| **Стабильность Windows** | Ошибки драйвера перехвата нередко вызывают синие экраны (BSOD) | Стабильная фоновая служба без вылетов и утечек памяти |
| **Discord и голосовые чаты** | Требует отдельных сложных настроек для работы голоса | Звонки, стримы и голосовые каналы работают нативно |

## Как это устроено

* **Встроенные профили** – в программу уже зашиты оптимизированные конфигурации под разные задачи (игры с низким пингом, YouTube в 4K, голосовой Discord и Telegram).
* **Официальный стек WireGuard** – подключение осуществляется через виртуальный сетевой адаптер Wintun (разработка WireGuard LLC). Трафик изолирован и передается на максимальной скорости вашего тарифа.
* **Автономная служба ScarletManager** – соединение держит системная служба, поэтому VPN не прерывается при закрытии или сворачивании главного окна.
* **Живой мониторинг сети** – встроенный график отслеживает задержку (ping) в реальном времени с наглядной цветовой индикацией.
* **Интеллектуальный выбор** – кнопка «Лучший профиль» автоматически тестирует серверы и выбирает профиль с наименьшим пингом.
* **Полная конфиденциальность** – программа не содержит аналитических трекеров, не собирает телеметрию и хранит данные локально на вашем ПК.

## Использование

### 1. Скачивание
Перейдите в раздел **[Releases](https://github.com/Sayziks/Scarlet/releases/latest)** и скачайте версию под ваш процессор:
* **`Scarlet X64.exe`** – для стандартных ПК и ноутбуков (Intel / AMD).
* **`Scarlet ARM64.exe`** – для устройств на Windows on ARM.

### 2. Установка
Запустите скачанный файл, подтвердите права администратора и нажмите **«Установить»**. Программа настроит всё необходимое за несколько секунд.

### 3. Подключение
В программе уже доступны встроенные профили. Просто выберите нужный и нажмите **«Подключить»** (или нажмите **«Лучший профиль»** для автоматического выбора самого быстрого сервера).

Если вы хотите использовать свои собственные конфиги, нажмите кнопку **«Добавить»** и скопируйте файлы `.conf` в открывшуюся папку.

### 4. Управление через трей
При нажатии на крестик окна SCARLET сворачивается в трей возле часов и продолжает держать соединение. Чтобы полностью закрыть программу, нажмите правой кнопкой мыши по значку в трее -> **«Выход»**.
